# 划词小窗 / Quicklook

在任意应用里选中文字，按一次热键，鼠标旁弹出一个置顶小窗：**翻译它**，或者**就它提问**。当前应用不会被切走，DSH 主窗口不会出现。

也可以框选屏幕上的一块区域，用 Windows 自带的 OCR 取字，或者直接把截图交给模型看。

## 它解决什么

在 Word、PDF 阅读器、浏览器里读东西时，查一个词要"复制 → 切到 DSH → 粘贴 → 删掉历史"。这个插件把这段路缩成一次按键，并且把结果留在一张小窗里，不污染对话。

## 组成

| 部分 | 位置 | 职责 |
|---|---|---|
| 插件（Host 半边） | DSH 进程内 | 归一化、提示词、模型调用、缓存、历史、术语表 |
| 壳 | `shell/quicklook.ps1`，由插件托管 | 全局热键、取词、框选截图、本地 OCR、开窗与置顶 |
| 小窗 | 插件在本地 `/qk/popup` 提供的网页 | 展示与交互 |

壳由插件通过 `subprocess` 启动，插件卸载或 DSH 退出时随之结束。

## 用法

| 热键 | 动作 |
|---|---|
| `Ctrl+Shift+Q` | 翻译选中的文字 |
| `Ctrl+Shift+E` | 就选中的文字提问 |
| `Ctrl+Shift+S` | 框选屏幕区域截图 |

热键在小窗的 `⋯` 里录制修改，改完自动重启壳。

> **不要用含 `Alt` 的组合。** 很多窗口里按下 Alt 会先激活菜单栏并吃掉选区，等到取词时已经没有可复制的文字了。默认值因此选了 `Ctrl+Shift+` 系列。

## 功能

### 换行归一化

从 PDF、Word 复制出来的句子常被硬折断。插件用纯代码处理，不消耗 token：

- 中文相邻直接拼接，其他情况补一个空格；
- 行尾连字符断词（`infor-\nmation`）会被修好；
- 段落空行保留；
- **代码、列表、表格不合并** —— 判定命中时即使开关是"强制开"也会跳过，并在卡片上说明原因。

### 翻译模式

只输出译文：不解释、不总结、不加括号注释。模型偶尔仍会加"（意为……）"，插件会剥掉这类附注；模型自作主张加的代码围栏也会去掉。

### 对话模式

默认开启输出预算：先一句结论，再最多 3 条要点，每条不超过 30 字。内容确实更长时给压缩版并提示可展开。这条对翻译模式不生效——译文不能被压短。

### 截图

框选后先走 **Windows 内置 OCR**（离线、免费、不消耗 token），识别结果直接出现在小窗里，可以改字后再翻译。

**直接把图发给模型**只支持对话模式，且需要当前默认模型支持图片输入；不支持时插件会明确报错，而不是假装看过。翻译模式永远不传图。

### 多卡片与钉住

默认新结果覆盖旧结果。点标题栏的「钉」进入累积模式：连续划词的结果会追加成卡片列表，适合读论文时边读边查。

### 历史、收藏与朗读

- 「史」打开历史（最近 20 条，可回看、可清空）；
- 每张卡片右上角的 `☆` 收藏，收藏构成生词本，可导出 Markdown；
- `读` 用系统语音朗读结果。

### 术语表

设置里每行写 `源=译`，翻译时作为硬约束拼进提示词。实测：`citation=引文` 会让译文直接使用「引文」。

## 边界（请先读这一段）

- **只支持能响应 Ctrl+C 的应用**。图片里的文字（用截图功能）、远程桌面、部分 PDF 阅读器拿不到，此时小窗会打开并给一个手动粘贴框，而不是静默失败。
- 取词会**短暂改写剪贴板再恢复**。如果某个程序占着剪贴板，恢复可能失败，属于已知限制。
- **选区前后文拿不到**。壳只能拿到复制出来的那一段，上下文只有前台窗口标题。
- **依赖 DSH 常驻**。模型与提示词都在插件里，DSH 完全退出后小窗打不开。
- 截图依赖 Windows 自带的 OCR 语言包；没有对应语言包时识别率会下降。
- **没有做 DSH 页内浮层**。壳已经覆盖了同样的场景，页内浮层需要额外把令牌注入页面才能画浮标，收益与风险不成比例，暂不实现。

## 隐私

选中文字会发送给你在 DSH 里配置的模型服务商。截图默认只在本机做 OCR；只有你点「发给模型」时图片才会离开本机。插件不把内容写入工作区，只在 `$DSH_HOME/plugin-data/dsh-quicklook/` 保存设置、历史与收藏。

## 验证状态

- 换行归一化与提示词：**23 项单元测试通过**（`node --test test/`）。
- Host 接口：`/qk/health`、`/qk/pick`、`/qk/translate`、`/qk/ask`、`/qk/capture`、`/qk/image`、`/qk/ocr`、`/qk/history`、`/qk/favorites` 均已用 `curl` 实跑验证。
- 术语表、缓存、历史落盘、收藏导出：实跑验证。
- **全局热键 → 取词 → 开窗**：热键已被系统接收（日志可证），但取词依赖向其他窗口注入 Ctrl+C。该动作无法在本会话的受限进程里验证，需要在本机手动按键确认。诊断写在 `%TEMP%\quicklook.log`。
